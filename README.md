# ExCalendar — Telegram бот для записи на индивидуальные тренировки

## Возможности
- клиенты видят доступные часы на ближайшие дни и бронируют слот (1 час);
- тренер (единственный администратор) получает запрос с кнопками `Принять/Отклонить`;
- при отклонении тренер может указать причину (необязательно) — клиент увидит её в ответе;
- клиенты отменяют запись из кнопки «🗓 Мои записи» (можно указать причину), тренер получает уведомление;
- у тренера есть кнопки «📘 Записи тренера» и «⚙️ Управление расписанием»: он видит сводку всех предстоящих слотов, может отменить подтверждённую тренировку (с указанием причины или без неё), а также **управляет доступностью слотов** — закрывает/открывает конкретные дни, недели или отдельные временные слоты;
- прошедшие тренировки автоматически удаляются из истории, свободные слоты снова становятся доступными;
- при подтверждении слот автоматически помечается занятым, клиенту приходит уведомление;
- **автоматические напоминания за 2 часа до тренировки** — и клиент, и тренер получают уведомление;
- все данные хранятся локально в `data/bookings.json`.

## Быстрый старт
1. Установите Python 3.11+ и создайте виртуальное окружение:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Скопируйте `config.env.sample` в `config.env` (или `.env`) и заполните:
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота;
   - `INSTRUCTOR_CHAT_ID` — Telegram ID тренера (получить через @userinfobot);
   - при необходимости измените рабочие дни/часы и горизонт бронирования.
3. (опционально) Если хотите переопределить значения локально, создайте `.env` — он
   перекроет параметры из `config.env`.
4. Запустите бота:
   ```
   python -m src.bot
   ```

## Как работает бот
- `/start` — бот показывает главное меню с кнопками:
  - `📅 Записаться` — открыть календарь ближайших свободных слотов;
  - `🗓 Мои записи` — список активных заявок с кнопками отмены (и полем для причины);
  - `📘 Записи тренера` — доступно только инструктору, список всех грядущих заявок;
  - `⚙️ Управление расписанием` — доступно только инструктору, настройка доступности слотов.
- Из раздела `📘 Записи тренера` инструктор может отменить любую ещё актуальную тренировку и при желании указать причину — клиент сразу получит уведомление.
- **Управление расписанием** (`⚙️ Управление расписанием`):
  - **Управление днями** — выбрать день и открыть/закрыть отдельные временные слоты или весь день целиком;
  - **Управление неделями** — массово закрыть или открыть всю неделю (понедельник–воскресенье);
  - **⚙️ Настройка рабочего времени** — глобальные настройки, применяемые ко всем датам:
    - выбор рабочих дней недели (Пн–Вс);
    - выбор часов работы (начало и окончание);
    - можно сбросить к настройкам по умолчанию из `config.env`;
  - закрытые слоты не отображаются клиентам в календаре и не могут быть забронированы;
  - все изменения сохраняются в `data/schedule_blocks.json`.
- Календарь листается стрелками `◀️ / ▶️`, поэтому можно выбрать дату дальше стандартных 2 недель (горизонт задаётся `BOOKING_HORIZON_DAYS`).
- `/help` — краткая инструкция (также доступна из кнопок).
- После выбора даты и времени клиент видит статус «ожидает подтверждения», а тренеру
  приходит карточка заявки.
- Тренер подтверждает или отклоняет запрос кнопками в чате. Клиенту сразу приходит результат.

## Настройки расписания
Параметры `.env` (используются по умолчанию, можно переопределить через бота):
- `TIMEZONE` — часовой пояс (по умолчанию `Europe/Moscow`);
- `WORKING_DAYS` — дни недели через запятую (`mon,tue,wed,thu,fri,sat`);
- `WORK_START_HOUR` / `WORK_END_HOUR` — первая и последняя граница слотов;
- `BOOKING_HORIZON_DAYS` — на сколько дней вперёд показывать календарь (до 30).

**Важно:** Тренер может изменить рабочие дни и часы через интерфейс бота (`⚙️ Управление расписанием` → `⚙️ Настройка рабочего времени`). Эти настройки применяются ко всем датам и имеют приоритет над значениями из `config.env`. Можно сбросить к настройкам по умолчанию.

Ежедневные слоты генерируются автоматически с шагом 1 час на основе текущих настроек.

## Структура проекта
```
src/
  bot.py            # запуск Telegram-бота и обработчики
  config.py         # чтение .env и настройка расписания
  booking_store.py  # хранение и проверка заявок
  schedule_manager.py  # управление закрытыми слотами
  keyboards.py      # inline-клавиатуры Telegram
data/
  bookings.json     # создаётся автоматически
  schedule_blocks.json  # закрытые слоты (создаётся автоматически)
```

## Технические детали
- Бот использует фоновую задачу (JobQueue), которая каждые 5 минут проверяет подтверждённые тренировки и отправляет напоминания за 2 часа до начала.
- В `data/bookings.json` каждая заявка содержит поле `reminder_sent` для отслеживания отправленных напоминаний.
- Прошедшие тренировки автоматически удаляются при любом взаимодействии с ботом.
- Закрытые слоты хранятся в `data/schedule_blocks.json` в формате `{"blocked_slots": {"YYYY-MM-DD": ["HH:MM", ...]}}`.
- При проверке доступности слотов учитываются как занятые заявки, так и закрытые тренером слоты.
