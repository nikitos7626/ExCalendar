 Telegram бот для записи на индивидуальные тренировки

## Функциональные возможности

### Для клиентов
*   **Календарь:** Просмотр доступных временных слотов (динамическая генерация).
*   **Бронирование:** Создание заявки на выбранное время (потребует подтверждения).
*   **Управление записями:** Просмотр активных заявок и возможность их отмены с указанием причины.
*   **Уведомления:** Получение статусов заявок (подтверждено/отклонено) и автоматических напоминаний за 2 часа до начала.

### Для инструктора (Администратора)
*   **Обработка заявок:** Получение входящих запросов с возможностью подтверждения или отклонения (с комментарием).
*   **Управление расписанием:**
    *   Гибкая настройка рабочих дней и часов.
    *   Блокировка конкретных дат, недель или отдельных часов.
    *   Переключение между автоматическим и ручным режимом формирования слотов.
*   **Мониторинг:** Просмотр списка всех предстоящих тренировок.

## Техническая реализация

*   **Стек:** Python 3.11+, python-telegram-bot (Telegram API).
*   **Хранение данных:** Брони — MySQL; блокировки расписания и настройки — JSON (`schedule_blocks.json`). Для MySQL нужна переменная `DATABASE_URL` в формате `mysql://user:password@host:3306/excalendar`.
*   **Фоновые задачи:** Использование `JobQueue` для периодической проверки расписания и отправки напоминаний.
*   **Конфигурация:** Управление параметрами через `config.env` / `.env` (часовой пояс, горизонт планирования, `DATABASE_URL`).

## Установка и запуск

1.  Создать виртуальное окружение и установить зависимости:
    ```bash
    python -m venv .venv
    .venv\Scripts\activate  # Windows
    pip install -r requirements.txt
    ```

2.  Настроить переменные окружения в файле `config.env` или `.env`:
    *   `TELEGRAM_BOT_TOKEN`
    *   `INSTRUCTOR_CHAT_ID`
    *   `DATABASE_URL` — строка подключения к MySQL, например `mysql://user:password@localhost:3306/excalendar`
    *   `TIMEZONE` (по умолчанию Europe/Moscow)

3.  Запустить бота:
    ```bash
    python -m src.bot
    ```

## Структура проекта

*   `src/bot.py`: Точка входа, инициализация бота и диспетчера.
*   `src/booking_store.py`: Логика работы с заявками (CRUD, валидация).
*   `src/schedule_manager.py`: Логика управления слотами и блокировками.
*   `src/config.py`: Загрузка конфигурации и валидация переменных окружения.
*   `data/`: Директория для хранения JSON-файлов с состоянием системы.
